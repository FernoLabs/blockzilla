# Blockzilla tools and services

- [CLI](cli/README.md): build, inspect, and convert archives.
- [Archive gateway](archive-gateway/README.md): serve completed generations through authenticated HTTP ranges.
- [Monitor](monitor/README.md): show scheduler and archive status.

Run the CLI from the workspace root with `cargo run -p blockzilla -- --help`.
V3 conversion is available as `blockzilla archive-v3 convert --help`.
