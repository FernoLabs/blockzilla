# Blockzilla compaction protocol

Dependency-light canonical persisted primitives for the Blockzilla V1
compaction boundary. This crate contains no scheduler, object-store client,
worker runtime, or catalog backend.

The normative contract is
[`docs/design/blockzilla-compaction-job-v1.md`](../../docs/design/blockzilla-compaction-job-v1.md).
